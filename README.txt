Iglesia Amor y Restauración - Dar en Línea web app

Files:
- index.html
- manifest.json
- apple-touch-icon.png

The Give button opens the exact Zeffy donation form:
https://www.zeffy.com/en-US/donation-form/tithes-and-offering-54

To install on iPhone:
1. Host these files on an HTTPS website (GitHub Pages, Vercel, Netlify, etc.).
2. Open the hosted index.html URL in Safari.
3. Share -> Add to Home Screen.
4. Turn on "Open as Web App" -> Add.

If you want, replace apple-touch-icon.png with your church logo (ideally a square PNG).
